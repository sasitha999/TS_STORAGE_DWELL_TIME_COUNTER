# Excel Transformer App

React + TypeScript app that uploads an Excel file, appends a computed column, and downloads an updated file.

## Features

- Excel upload for .xlsx and .xls files
- Parses first worksheet
- Adds a new DummyComputedValue column
- Shows a preview table for the first 8 transformed rows
- Downloads transformed workbook as .xlsx

## Libraries

- @mui/material + @mui/icons-material
- xlsx
- file-saver

## Scripts

- npm run dev
- npm run build
- npm run preview
